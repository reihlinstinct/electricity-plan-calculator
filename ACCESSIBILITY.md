# Accessibility statement

We want the electricity plan calculator to be usable by everyone. Our target is WCAG 2.2
level AA for the web page (web/index.html, web/guide.html, web/sources.html).

## What we do

- Semantic markup and keyboard-navigable controls (native inputs, buttons and links).
- Right-to-left Hebrew layout with readable contrast and scalable text.
- All computation runs locally in the browser; the page works without a network connection
  after load, so no spinner or timeout blocks assistive technology.

## Known limitations

- The plan-ranking bars are color-coded; the numeric values are always shown next to them
  so color is never the only signal.

Feedback: open an issue on GitHub.
