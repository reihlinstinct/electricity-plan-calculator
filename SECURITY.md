# Security policy

## Supported versions

Only the latest state of the `main` branch is supported. Security fixes are made there.

| Version | Supported |
| ------- | --------- |
| latest `main` | yes |
| older | no |

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub:
[Report a vulnerability](https://github.com/reihlinstinct/electricity-plan-calculator/security/advisories/new).

Do not open a public issue for a security problem. Never include real consumption data,
contract numbers, meter numbers, addresses or other private data in a report; use
synthetic values (see data/sample_consumption.csv for the format).

You can expect an acknowledgement within a few days. Confirmed issues are fixed on `main`
and disclosed in a GitHub security advisory once a fix is available.
